    The image domain impulse response widths (IRWs) are key attributes of the image. The half
    power impulse response widths are Row_IRW and Col_IRW. For most images, the impulse
    Row_IRW = Row.ImpRespWid Col_IRW = Col.ImpRespWid
    Krow_IRBW = Row.ImpRespBW Kcol_IRBW = Col.ImpRespBW

  ---- page 174 ----
    XML: Row.ImpRespBW
    Range spacing Rg_SS and impulse response width Rg_IRW are in meters. Impulse response
    broadening factor kRG is associated with weighting function wRG(s). For uniform weighting,
    kRG = 0.886.
    RGkRg_IRW Krg_IRBW= XML: Row.ImpRespWid

    response broadening factor kAZ is associated with weighting function wAZ(s). For uniform
